# Matrix Operations in C

## Project Description

A simple C program to add two matrices. The user enters the size and elements of two matrices, and the program displays their sum.

## Features

- Enter matrix elements
- Add two matrices
- Display the result

## Technologies Used

- C
- Arrays
- Loops

## How to Run

Compile and run the `matrix_operations.c` file using a C compiler.
